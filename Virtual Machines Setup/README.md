# 🖥️ Virtual Machines Setup

## 📌 Overview

As part of my cybersecurity learning journey, I am learning how to use **Virtual Machines (VMs)** to create safe and isolated environments for practicing Linux, networking, and cybersecurity.

A virtual machine allows me to run another operating system inside my main operating system without installing it directly on my computer.

---

## 🎯 Beginner Learning Process

I am following this basic process:

```text
1. Understand Virtualization
        ↓
2. Install VirtualBox
        ↓
3. Download a Linux ISO
        ↓

        ↓
5. Configure RAM, CPU & Storage
        ↓
6. Install Linux
        ↓
7. Configure VM Networking
        ↓

        ↓

        ↓
10. Build a Cybersecurity Lab
```

## 🧠 Step 1 — Understand Virtualization

First, I am learning what virtualization is and how a virtual machine works.

A VM uses the resources of my physical computer while running as a separate virtual environment.

### Important concepts

* Host Operating System
* Guest Operating System
* Virtual Machine
* Virtual CPU
* Virtual RAM
* Virtual Storage
* Virtual Network Adapter

---

## 🛠️ Step 2 — Install VirtualBox

I use **VirtualBox** to create and manage virtual machines.

The basic process is:

```text
Install VirtualBox
        ↓
Open VirtualBox
        ↓
Create New VM
        ↓
Select Operating System
        ↓
Assign Resources
        ↓
Attach ISO
        ↓
Start VM
```

---

## 🐧 Step 3 — Install Linux

I am using Linux as my primary operating system for cybersecurity practice.

The VM installation process includes:

* Selecting the Linux ISO
* Creating virtual storage
* Allocating RAM and CPU
* Starting the VM
* Installing Linux
* Completing the initial configuration

---

## 🌐 Step 4 — Understand VM Networking

Networking is an important part of cybersecurity labs.

I am learning the basic VM networking modes:

* NAT
* Bridged Adapter
* Host-Only Adapter

The goal is to understand how my virtual machine communicates with:

```text
Internet
   ↕
Host Machine
   ↕
Virtual Machine
```

## 🔐 Step 5 — Build a Safe Cybersecurity Lab

After understanding the basics, I will use virtual machines to create an isolated environment for cybersecurity practice.

This environment can be used for:

* Linux practice

* Security tools

I will practice only in systems and environments that I own or have permission to test.

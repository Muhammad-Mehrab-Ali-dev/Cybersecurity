# 🐧 Linux Journey 

# Story of Linux

## 🏠 1. UNIX was Born (1969)

👨‍🔬 **Ken Thompson** and **Dennis Ritchie** developed **UNIX** at Bell Labs.

Initially, UNIX was written in **Assembly Language**.

### Memory Trick

> **UNIX = Father of Linux**

---

## 🖥️ 2. UNIX Becomes Portable (1973)

Dennis Ritchie created the **C Programming Language**.

UNIX was then rewritten in **C**, making it portable across different computer systems.

### Why was this important?

Without C, UNIX could only run on one type of computer.

### Memory Trick

> **C = Carry UNIX Everywhere**

---

## 🌍 3. Richard Stallman Starts GNU (1983)

Richard Stallman believed software should be free to use, modify, and share.

He started the **GNU Project**.

**GNU** stands for:

> **GNU's Not UNIX**

### Goal

To create a completely free UNIX-like operating system.

GNU successfully developed almost every component of an operating system except one important part—the kernel.

---

## ⚙️ 4. GNU Introduces GPL (1985)

GNU released the **GNU General Public License (GPL).**

### GPL allows users to:

- Use software freely
- Modify the source code
- Share software with others

The GPL became one of the foundations of the **Open-Source Software Movement**.

---

## ❌ 5. GNU's Kernel (Hurd) Remained Incomplete (1990)

GNU attempted to develop its own kernel called **Hurd**.

However, Hurd was never completed successfully.

GNU now had everything needed for an operating system except a working kernel.

---

# 💡 What is a Kernel?

The **Kernel** is the **core component of an operating system**.

It acts as a bridge between **software** and **hardware**, allowing them to communicate.

The kernel is responsible for managing:

- CPU
- Memory (RAM)
- Hard Disk
- Keyboard
- Mouse
- USB Devices
- Network Devices

Without the kernel, an operating system cannot function.

## Communication Flow

```text
User
   ↓
Applications
   ↓
Kernel
   ↓
Hardware
```

## Example

1. You open Chrome.
2. Chrome sends a request to the kernel.
3. The kernel communicates with the CPU and RAM.
4. The hardware performs the requested task.

### Memory Trick

> **Kernel = Brain of the Operating System**

| Human Body | Computer |
|------------|----------|
| Brain | Kernel |
| Hands, Eyes, Ears | Hardware |
| Daily Activities | Applications |

---

# 🐧 6. Linus Torvalds Creates Linux (1991)

A Finnish computer science student named **Linus Torvalds** developed a new kernel as a personal project.

This kernel became known as the **Linux Kernel**.

It provided the missing component needed by GNU.

---

# 🎉 7. GNU + Linux (1992)

Combining the GNU tools with the Linux Kernel resulted in a complete operating system.

```text
GNU + Linux Kernel = GNU/Linux
```

This became the foundation of the modern Linux operating system used around the world.

---

# 🎯 Key Takeaways

- UNIX is considered the father of Linux.
- Rewriting UNIX in C made it portable.
- GNU aimed to create a free UNIX-like operating system.
- GPL promoted free and open-source software.
- Hurd was GNU's unfinished kernel.
- Linus Torvalds developed the Linux Kernel.
- GNU and Linux together formed the GNU/Linux operating system.
